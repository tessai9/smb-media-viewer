# Product Overview

A lightweight web viewer for media files stored on a home Samba NAS, accessible from a browser on the local network — including older smartphones over Wi-Fi.

## Core Capabilities

- **Directory browsing**: Navigate mounted NAS directories as a grid of thumbnails
- **Media viewing**: View images, play videos, and read PDFs using browser-native capabilities
- **Lazy thumbnail loading**: Thumbnails generated on-demand and cached to disk; memory-efficient infinite scroll
- **Low resource footprint**: Compiled binary, minimal CPU/memory usage for always-on mini-PC hosting

## Target Use Cases

- Browsing a photo/video/document library from any device on the home network
- Viewing media on old mobile browsers without app installation

## Value Proposition

Minimal dependencies, minimal resources. No cloud, no auth, no frameworks — just a fast binary serving files from a CIFS mount with smart thumbnail caching.
