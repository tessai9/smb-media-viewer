# 実装計画

## タスク一覧

- [x] 1. FileBrowser サービスへのソートロジックの追加
- [x] 1.1 ソートキーとソート方向の列挙型およびパース関数の実装
  - ソートキー（名前・作成日時・更新日時）と方向（昇順・降順）をそれぞれ列挙型として定義する
  - 文字列からソートキーを変換する関数を実装し、無効な値や存在しない値に対してはデフォルト（名前）を返す
  - 文字列からソート方向を変換する関数を実装し、無効な値に対してはデフォルト（昇順）を返す
  - _Requirements: 1.1, 1.2, 2.1, 2.2, 4.3_

- [x] 1.2 FileEntry への作成日時フィールドの追加
  - FileEntry 構造体にソート専用の作成日時フィールドを追加する
  - このフィールドは JSON シリアライズ対象から除外し、API レスポンスには含めない
  - ディレクトリ走査時に各エントリの作成日時をファイル情報から読み取って設定する
  - _Requirements: 1.1_

- [x] 1.3 list_entries のパラメータ化とソートロジックの拡張
  - list_entries がソートキーとソート方向を引数として受け取れるよう拡張し、デフォルト値（名前・昇順）を設定して既存の呼び出し元を変更不要にする
  - ソート comparator を拡張し、ソートキー（名前・作成日時・更新日時）に応じて比較値を切り替える
  - ソート方向が降順の場合は比較を逆転させる
  - ディレクトリグループとファイルグループを分離した上で各グループ内にソートを適用し、ディレクトリが常に先頭に来ることを保証する
  - offset の計算はソート済みの全エントリリストを基準とし、範囲外は空配列を返す（既存動作を維持）
  - _Requirements: 1.1, 1.3, 2.3, 2.4, 2.5, 3.1, 3.2, 3.3, 6.2, 6.3_
